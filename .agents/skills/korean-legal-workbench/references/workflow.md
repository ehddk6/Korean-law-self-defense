# 상담·사건 작업 계약

## 상담

상담은 목표, 사건 단계, 행위일·송달일, 상대방, 이미 취한 조치, 보유 증거와 긴급성을 먼저 확인한다. 답변은 일반 설명, 사실 적용, 반대 가능성, 선택지, 기한, 즉시 행동과 미확인 사항으로 구성한다.

상담에서 공식 근거나 핵심 사실이 부족하면 결론을 보류한다. 상담이 소송 준비로 전환될 때 사건 레코드를 생성한다.

## 사건 단계

`intake → safety_checked → ingested → facts_fixed → issues_mapped → researched → independently_analyzed → drafted → audited → released`

단계를 건너뛰거나 되돌리지 않는다. 새 증거가 늦게 발견되면 새 사건 버전으로 다시 수집한다.

`legal research`는 조사 입력만 만들고 상태를 `issues_mapped`에 둔다. P1 원문 파일, 적용시점, 유리·불리 근거를 등록한 뒤 `legal research --complete`가 통과해야 `researched`가 된다. 분석도 입력 묶음 생성과 결과 고정을 분리하며, 감사 뒤 자료·분석·초안 해시가 바뀌면 export를 차단한다.

## 사실과 증거

- 확정 사실은 하나 이상의 EvidenceRecord를 요구한다.
- 추론과 상대방 주장을 확정 사실 문장에 섞지 않는다.
- 증거의 입수경위, 원본 해시, 페이지·문단, 진정성립과 증명력 쟁점을 기록한다.
- OCR 텍스트는 원본 화면 대조 전에는 정확한 인용으로 사용하지 않는다.

## 산출물

사용자 검토 패키지는 초안, 증거목록, 근거표, 기한표, 감사보고서와 manifest를 포함한다. 배포는 제출을 의미하지 않는다.
